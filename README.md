# Misión Órbita

Misión Órbita es un simulador de misiones espaciales hecho en Python. En este primer avance, los programas ayudan a planear la misión, calculando y verificando los recursos necesarios.

## Integrantes

- Esteban Víquez Rodríguez

## Convenciones y estilos

- Variables en snake_case (ejemplo: dias_viaje)
- Constantes en MAYÚSCULAS con guion bajo (ejemplo: RESERVA_COMBUSTIBLE)
- Indentación de 4 espacios

## Cómo ejecutar

1. Entrar a la carpeta: cd avance1
2. Ejecutar el programa que quieras: python nombre_del_archivo.py

Programas disponibles:

- ejercicio1_recursos.py
- ejercicio2_combustible.py
- ejercicio3_soporte_tripulacion.py
- ejercicio4_autorizacion.py
